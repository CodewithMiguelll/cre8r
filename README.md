# Cre8r

Cre8r is a growing digital platform built to celebrate and spotlight Nigerian creatives across art, design, writing, and visual storytelling. It is still under development, but the vision is already clear: create a beautiful, community-driven space where creators can share their work, connect with audiences, and be discovered.

## What Cre8r is

Cre8r brings together:

- talented Nigerian artists and designers
- emerging and established creators
- audiences looking for fresh, authentic cultural expression
- a space for featured work, creative discovery, and community connection

The experience is designed to feel inspiring, modern, and welcoming, with a strong focus on showcasing creativity rather than just presenting portfolios.

## Current Focus

At the moment, Cre8r is centered around:

- an elegant landing experience for the brand
- featured creator discovery
- community-oriented creative storytelling
- a foundation for future exhibits, profiles, and creator engagement features

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/CodewithMiguelll/cre8r.git
   cd cre8r
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Run the development server
   ```bash
   npm run dev
   ```

4. Open your browser and visit
   ```text
   http://localhost:3000
   ```

## Tech Stack
